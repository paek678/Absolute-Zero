# 모드별 게임 진행 및 연출 흐름

기획자와 개발자가 현재 게임의 동작을 함께 확인하기 위한 문서입니다. 2026-10-01 기준 구현을 확인했으며, 온라인 1대1·온라인 3~4인전·로컬 봇전의 입장, 조작, 전투, 카메라와 캐릭터 연출, 사망, 결과, 퇴장까지 설명합니다. 새로운 기획안이 아니라 **현재 코드와 데이터가 실행하는 동작**을 정리했습니다. 아래 시간은 설정된 대기 시간과 연출 시간입니다. 프레임 저하나 통신 지연이 있으면 실제 경과 시간은 달라질 수 있습니다.

## 먼저 알아둘 기준

- **턴**은 준비와 전투를 한 번 진행하는 단위입니다. **라운드**는 모드별 사망 조건을 만족하면 끝납니다. **경기**는 1대1·봇전에서 2라운드를 먼저 이기면, 3~4인전에서 확정된 행동 또는 효과 묶음으로 누군가 먼저 5킬에 도달하면 끝납니다.
- 서버가 입력을 검사하고 전투 결과를 확정한 뒤, 각 화면이 그 결과를 연출합니다. 화면에서 타격이 보일 때 피해를 다시 적용하는 구조는 아닙니다.
- 전투 시작 시 온도 표시는 전투 전 수치에 잠시 고정됩니다. 각 아이템의 효과 시점에 해당 결과 온도를 표시하며, 게이지는 **회복 시 초당 15°, 감소 시 초당 6°**로 움직입니다. 연출 종료 시 임시 표시를 해제합니다. 게이지가 아직 목표 수치에 도달하지 않았다면 연출이 끝나도 부드럽게 계속 움직입니다.
- **내 화면에서 연출이 끝나는 시점**과 **다음 턴이 시작하는 시점**은 다릅니다. 서버는 보통 연결된 모든 사람의 화면에서 연출 완료 응답을 받을 때까지 기다립니다. 봇전에서는 사람 한 명의 응답만 기다리며, 봇에게 별도 응답을 요구하지 않습니다.
- 캐릭터·아이템·카메라 위치는 현재 맵의 배치 정보를 사용합니다. 내 행동은 1인칭 손과 아이템으로, 상대 행동은 상대 캐릭터의 애니메이터로 보여줍니다. 보류 중인 사이드 스프라이트 실험은 현재 기본 연출 경로에 포함하지 않습니다.

## 공통: 입장부터 첫 준비 단계까지

1. **온라인:** 온라인 방에서 호스트가 시작합니다. Relay 연결 공간 생성, 호스트 실행, 참가 코드 공개 후 네트워크 씬을 불러옵니다. 클라이언트는 Relay 세션에 참가하고 호스트의 씬 이동을 따라갑니다. **봇전:** 로비의 봇전 버튼으로 선택·미리보기 화면을 열고 시작을 누르면, 대전 설정을 확정하여 내부 NGO 로컬 호스트를 실행합니다. UGS나 Relay는 사용하지 않습니다.
2. 씬 로딩 작업 또는 네트워크 씬 이벤트에 맞춰 로딩 화면이 켜집니다. 도움말과 진행률을 표시하며 우선 85%까지 진행합니다. 이 수치는 실제 파일 용량을 측정한 값이 아니라 화면용 진행률입니다.
3. TurnManager는 필요한 참가자, 플레이어 식별 정보, 인벤토리, ItemManager, MatchManager가 준비될 때까지 `WaitingForPlayers`에서 기다립니다. 봇전은 사람과 봇을 직접 생성하고 필요한 화면 오브젝트까지 기다립니다. 초기화 실패 시 실패 처리로 이동하며, 플레이어가 빠진 상태로 준비 단계를 시작하도록 설계되어 있지는 않습니다.
4. 캐릭터 꾸미기, 맵의 배치 기준점, 아이템 위치, 카메라·1인칭 화면, 상태 표시를 연결합니다. 1대1·봇전은 두 자리를 사용합니다. 3~4인전은 내 자리를 남쪽으로 보여주고 상대 자리를 서쪽·북쪽·동쪽에 대응시킵니다. 3인 방에는 상대 두 자리만 채웁니다.
5. 시작 온도는 37°입니다. 현재 일반적인 1대1·봇전 초기화는 기본 아이템과 랜덤 아이템 4개를 지급합니다. 3~4인전은 기본 아이템과 랜덤 아이템 2개로 시작하며, 랜덤 아이템은 최대 4개까지 보유합니다. 규칙 데이터인 SO의 값만 바꿔도 기존 1대1 초기화 경로 전체가 바뀌는 것은 아닙니다.
6. `WaitingForPlayers`를 벗어나면 로딩 진행률을 100%로 채우고 0.4초 유지합니다. 이후 불투명도를 초당 3씩 낮춰 약 0.33초 동안 사라지게 하고 로딩 Canvas를 제거합니다. 실패·퇴장 시에는 더 일찍 강제로 숨길 수 있습니다.

## 온라인 1대1 상세 흐름

### 1. 준비 시작

1. 턴 수를 올리고 선택한 행동, 준비 완료 상태, 턴별 보정값, 관련 임시 상태를 초기화합니다. 선풍기를 켭니다. 첫 1초 주기에서는 선풍기 냉각을 건너뜁니다.
2. 준비 시간과 입력 가능 구간을 알립니다. 일반 준비 시간은 20초, 여름방학 환경에서는 10초입니다.
3. `PREP PHASE`, 아이템 조작, 준비 버튼, 시계를 표시하고 선풍기 소리를 재생합니다. 마지막 5초는 빨간 카운트다운·경고·초침 소리를 사용합니다. 준비 단계가 끝나면 경고도 멈춥니다.
4. 준비 완료 전에는 보통 선풍기로 초당 1°가 내려갑니다. **아이템을 선택하는 것만으로는 선풍기가 꺼지지 않습니다.** 준비 완료를 눌러야 꺼지며, 이후 다른 참가자를 기다리는 동안 보통 초당 1°를 회복합니다. 회복량은 환경에 따라 달라집니다.

### 2. 아이템 선택과 확정

1. 사용 가능한 아이템을 클릭합니다. 자신에게 쓰는 아이템은 자신을, 공격 아이템은 유일한 상대를 대상으로 지정합니다. 3~4인전처럼 마우스로 상대를 조준하는 단계는 없습니다.
2. 서버가 현재 턴, 소유권, 선택한 아이템의 개별 식별 정보, 사용 가능 여부, 대상을 검사합니다. 일반 아이템은 이번 턴의 행동으로 예약됩니다. 이때 전투 애니메이션이 시작되지는 않습니다.
3. 미니게임이 필요한 아이템이면 소유자 화면에서 미니게임을 시작합니다. 성공 결과가 유효한 시간 안에 도착해야 행동이 예약됩니다. 유효한 입력 시간 안에서 실패하면 사용 횟수 1회를 소모하고 행동은 예약하지 않습니다. 기한이 지났거나 이전 턴에 속한 결과는 거부하며, 정상적인 실패와 구분합니다.
4. 준비 완료 전에는 확정된 아이템을 다시 눌러 선택 취소를 요청할 수 있습니다. 준비 완료 후에는 선택을 잠급니다. 아이템 없이 준비 완료하는 것도 가능하며, 이 경우 주 행동이 없습니다.
5. 양쪽이 준비 완료하거나 시간이 끝나면 입력을 닫습니다. 미완료 플레이어는 강제로 준비 완료 처리하고 먼저 준비한 사람의 표시를 전달합니다. 직전에 이모티콘을 시작했다면 1초 표시 시간 중 남은 부분을 마친 뒤 전투에 들어갈 수 있습니다.

### 3. 전투 판정과 화면 연출

1. `AttackPhase`로 들어가 준비 버튼·카운트다운 조작을 숨기고 선풍기 소리를 멈춥니다. 이번에 적용할 지연 버프·디버프를 처리한 뒤, 선택 행동을 판정하기 전 1초 기다립니다.
2. 먼저 준비 완료한 플레이어가 선행합니다. 동률이면 현재 온도가 낮은 쪽, 그것도 같으면 0번 자리가 먼저입니다. 폭염에서는 온도가 낮은 쪽을 준비 순서보다 우선합니다.
3. 공격 전에 유효한 방어를 적용하고 아이템 규칙에 따라 사용 횟수를 소모합니다. 첫 번째 주 행동을 판정하고, 상대를 죽였다면 사망한 상대의 후속 행동을 취소합니다. 죽이지 않았다면 두 번째 행동도 판정합니다.
4. 행동·효과 기록이 포함된 결과를 모든 화면에 전달합니다. 각 화면은 인벤토리 재배치를 잠그고 전투 전 온도를 유지합니다. 첫 아이템 연출 전 0.5초 기다립니다.
5. 첫 번째 방어 외 행동을 재생합니다. 행동하는 본인은 1인칭 손·아이템을 보고, 다른 사람은 행동자의 캐릭터·손에 든 아이템을 봅니다. 현재 행동자 표시도 켭니다. 아이템별 타격·종료 시점은 아래 표를 따릅니다.
6. **방어에는 별도 행동 시간이 없습니다.** 들어오는 효과가 선택한 방어에 막혔다면 그 공격의 타격 시점에 대상의 방어 애니메이션을 함께 시작합니다. 선풍기의 반복 타격 표현마다 다시 시작하지 않고 첫 타격에서 한 번만 실행합니다. 방어 후에도 피해가 남았다고 결과에 기록된 경우에만 피해 반응을 표시합니다.
7. 첫 행동에서 사망했다면 즉시 해당 대상의 사망 연출을 재생하고 전체 순서를 마칩니다. 그렇지 않으면 양쪽 모두 방어 외 행동이 있을 때만 0.3초 간격을 둔 뒤 두 번째 행동과 그에 따른 사망 연출을 재생합니다.
8. 사망 없이 끝나는 1대1 전투는 도입부를 포함한 **전체 연출을 최소 3초**로 맞춥니다. 플레이어마다 3초가 아닙니다. 첫 행동으로 사망한 분기는 사망 연출 후 종료하므로 일반적인 최소 시간 보충 분기를 사용하지 않습니다.
9. 임시 위치·빌려 쓴 아이템 표시를 복구하고, 인벤토리 잠금·행동자 표시·임시 온도 표시를 해제한 뒤 연출 완료 응답을 보냅니다. 서버는 필요한 화면의 응답을 최소 15초의 제한 시간으로 기다립니다. 이후 1초 더 기다린 뒤 `ResolutionPhase`로 넘어갑니다.

### 4. 다음 턴 또는 라운드 종료

- **승자가 없을 때:** 인벤토리 빈자리를 정리하고 1초 기다린 뒤 다음 준비를 시작합니다. 첫 턴이 끝났고 아직 환경이 없다면 다음 준비 전에 4초짜리 환경 안내를 넣습니다.
- **라운드 승자가 나왔을 때:** 결과와 라운드 승리 1회를 반영하고 `RoundOver`에 들어갑니다. 서버는 진행을 6초간 유지합니다. 같은 사망 연출을 반복 요청해도 이미 완료했는지 확인하여 중복 재생을 막습니다.
- **준비 중 사망했을 때:** 일반적인 두 행동 전투를 건너뜁니다. `HandleRoundEnd`에서 사망과 결과를 같은 경로로 전달합니다. 공격 중 사망과 달리 전투 연출 완료 응답을 먼저 기다린 다음 결과를 전달하는 경로는 아닙니다.
- **경기가 아직 끝나지 않았을 때:** 결과 화면을 닫고 온도를 37°로 초기화합니다. 관련 인벤토리·온도 구간 보상·턴 상태·환경·표시를 정리하고 시작 랜덤 아이템을 지급한 뒤 새 라운드를 엽니다. 온도 게이지는 준비 진입 시 갑자기 점프하지 않고 부드럽게 올라갑니다.
- **2라운드 선승으로 경기가 끝났을 때:** 최종 승리·패배를 표시합니다. 서버의 라운드 종료 대기 후 두 사람 모두 연결되어 있으면 15초 재대결 투표를 엽니다. 둘 다 수락하면 초기화 후 재시작하고, 거절·시간 초과·연결 해제 시 퇴장합니다. 네트워크 이벤트가 결과 애니메이션보다 먼저 와도 결과 화면과 투표 상태를 맞춥니다.

## 온라인 3~4인전 상세 흐름

### 1. 배치와 입력

1. 각자 자신의 아이템을 남쪽에서 봅니다. 상대와 상대 아이템은 해당 상대의 맵 기준점에 맞춰 배치하며, 내 아이스박스는 남쪽 중앙에 둡니다.
2. 일반 준비 시간 20초, 선풍기 냉각, 준비 완료 후 회복, 카운트다운, 아이템 미니게임을 공유합니다. 준비 완료 인원은 생존자만 계산합니다. 유령은 별도 스킬 패널을 사용합니다.
3. 단일 대상 아이템은 **아이템 클릭 → 마우스로 조준 → 유효한 생존 캐릭터 근처에서 화살표 고정 → 좌클릭으로 대상 확정** 순서입니다. 화살표는 아이템에서 출발하여 캐릭터 아래쪽을 가리킵니다. 좌우 대상은 곡선, 정면으로 분류된 대상은 직선으로 표시합니다. 고정 범위를 벗어나면 끝점이 다시 마우스를 따라갑니다.
4. 같은 아이템 재클릭·Esc·우클릭으로 조준을 취소합니다. 대상까지 확정한 후에도 준비 완료 전에는 해당 아이템 재클릭으로 취소할 수 있습니다. 준비 완료, 단계 변경, 아이템 식별 정보 상실, 대상 무효화 시 해당 선택·조준 경로를 닫습니다. 자신에게 쓰는 아이템은 상대 클릭을 요구하지 않습니다.

### 2. 서버 판정과 연출 재생

1. 전투 진입 시 생존자와 유령의 입력을 닫습니다. 적용 시점이 된 지연 효과를 먼저 처리합니다. 여기서 사망하거나 5킬이 나오면 일반 아이템 행동 전에 라운드·경기가 끝날 수 있습니다.
2. 전투 진입 후 1초를 기다리고 방어 준비와 아이템 소모를 처리합니다. 일반 행동은 준비 완료가 기록된 서버 시점, 낮은 온도, 자리 번호 순으로 정렬합니다. 폭염에서는 온도를 먼저 비교합니다. 방어는 판정상 먼저 적용하지만 별도 연출 대기 시간을 받지 않습니다.
3. **행동 하나씩 효과 → 온도 → 사망 → 킬 획득 → 5킬 확인** 순서로 확정합니다. 죽은 행동자의 대기 행동은 취소합니다. 경기 승자가 확정되면 이후 행동을 더 확정하지 않습니다. 한 번에 확정한 효과 묶음에서 여러 명이 5킬에 도달하면 공동 우승입니다.
4. 실제 확정된 이벤트 묶음만 전달합니다. 각 화면은 전투 전 온도와 인벤토리 배치를 유지하고, 0.5초 후 전달받은 행동 순서대로 재생합니다.
5. 방어 외 아이템 행동은 각각 **최소 3초**를 차지합니다. 설정된 애니메이션·전용 연출이 더 길면 그 시간을 사용합니다. 짧으면 실제 애니메이션이 끝난 뒤 남은 시간을 채웁니다. 빈 행동이나 취소된 행동에는 시간을 배정하지 않습니다.
6. 방어 반응은 공격자의 타격과 겹쳐 재생합니다. 빙의로 무력화된 일반 아이템은 정상 효과 대신 무력화 표시를 보여주되 해당 행동의 최소 시간은 유지합니다. 무력화된 방어는 표시만 재생하고 별도 방어 시간을 추가하지 않습니다.
7. 행동의 연출 시간이 끝나면 그 행동으로 사망한 대상을 한 명당 한 번씩 연출합니다. 뒤에 행동이 더 남아 있고 이번 행동에 사망 연출이 없었을 때만 0.3초 간격을 추가합니다. 취소되었거나 서버가 확정하지 않은 행동은 나타나지 않습니다.
8. 최종 온도를 표시하고 임시 연출 상태를 복구한 뒤 완료 응답을 보냅니다. 서버 대기 제한은 도입·통신 여유, 행동 시간, 행동별 여유, 간격, 사망 연출을 합산하며 설정된 최소 10초보다 짧지 않습니다. 종료 조건이 아닌 전투는 이후 1초 기다리고 `ResolutionPhase`로 이동합니다.

### 3. 사망·유령·2명 생존 전환

1. 온도 0이 되면 사망을 확정하고 해당 자리의 생존자 행동을 취소합니다. 화면에서는 얼어붙는 연출 후 얼음을 깨고 현재의 간단한 유령 임시 표시로 전환합니다. 최종 유령 아트는 이 문서에서 확정하지 않습니다.
2. 생존자가 2명 이상이면 중간 사망만으로 라운드를 끝내지 않습니다. 유령은 일반 아이템을 사용할 수 없고 준비 단계에 유령 스킬 패널을 사용합니다. 생존자 대상 일반 아이템으로 유령을 지정할 수 없습니다.
3. 해당 라운드에서 처음 생존자가 2명이 되면 **기존 랜덤 아이템을 유지하고 빈칸만 최대 4개까지 채웁니다.** 새 아이템 4개로 교체하지 않습니다. 중복 지급과 오래된 선택 정보가 남는 문제를 방지하는 검사를 거칩니다.
4. 생존자가 1명 이하가 되면 상황에 맞춰 `SURVIVED`, `FROZEN`, `ALL OUT`을 표시합니다. 경기가 아직 끝나지 않았다면 6초 대기 후 다음 라운드에 참여하는 자리들을 37°로 초기화합니다. 누적 킬은 유지합니다. 랜덤 아이템은 3~4인전 시작 지급 수로 초기화하고, 유령의 라운드별 재사용 대기·대상 기록은 정리합니다. **이미 사용한 빙의는 경기 내내 사용한 상태로 유지합니다.**
5. 유령 킬을 포함해 5킬이 나오면 해당 행동 경계에서 승자를 확정합니다. 이후 행동이나 다음 라운드는 진행하지 않습니다. 승리를 결정한 연출을 끝낸 뒤 최종 결과를 표시하며 공동 우승도 가능합니다. 결과 글자가 나타나면 로비 버튼을 활성화하고 3초 후 자동 퇴장합니다. 1대1 방식의 재대결 투표는 없습니다.

## 로컬 1대 봇전 상세 흐름

1. 로비의 봇전 버튼 → 대전 미리보기·선택 → 시작 → 내부 NGO 로컬 호스트 → 전용 `GameScene_Solo` 순서입니다. 사람은 네트워크 연결 하나를 사용하고, 봇은 서버가 제어하는 별도 논리 자리입니다. 일반 봇전에서는 UGS·Lobby·Relay 세션을 만들지 않습니다.
2. 현재 기본 대전은 1대1의 시작 온도 37°와 인벤토리 초기화를 따릅니다. 향후 조정을 위해 대전 구성, 봇, 난이도, 스탯, 아이템 사용 정책, 행동 트리 그래프를 별도 설정으로 참조합니다.
3. 유효한 준비 구간마다 행동 트리(BT)가 공개된 상태를 확인하고, 사용 가능한 아이템 후보를 만들고, 전술·아이템을 고릅니다. 생각 시간을 기다린 뒤 사용을 요청하고, 설정된 아이템 페널티 시간을 기다려 아이템 예약과 준비 완료를 진행합니다. 생존 위험 구간이 바뀌면 다시 판단할 수 있으며, 재시도 횟수와 실패 시 대체 행동에는 한계가 있습니다.
4. 현재 기본 생각 시간은 0.2~0.45초이고, 마감이 가깝거나 온도가 위험하면 짧아집니다. 기본 아이템 지연은 0.75초, 일부 미니게임 아이템은 1.5초입니다. 이 값은 임시 조정값이며 최종 난이도 밸런스는 아닙니다.
5. **봇은 미니게임을 열거나 풀지 않습니다.** 서버가 관리하는 사용 지연이 페널티입니다. 사람은 기존 미니게임 화면을 사용합니다. 생각·사용 지연 중에도 봇은 준비 단계의 냉각을 받으며, 이전 턴 작업을 뒤늦게 확정할 수 없습니다.
6. 사람과 봇이 모두 준비하면 앞서 설명한 1대1 판정, 공격과 동시 방어, 첫째·둘째 공격, 특수 아이템, 얼어붙기, 라운드 결과, 환경 흐름을 그대로 따릅니다. 사람은 자신의 1인칭 팔과 봇 캐릭터의 동작을 봅니다. 봇 전용 공통 공격 컷신이 따로 있는 것은 아닙니다.
7. 2라운드 선승 시 최종 결과를 엽니다. 다시 하기·로비 버튼은 클릭할 때까지 유지되며 상대 투표나 자동 퇴장 카운트다운이 없습니다. 다시 하기는 기존 로컬 세션과 봇 제어를 종료·초기화한 뒤 새 로컬 경기를 시작합니다. 로비 선택은 로컬 호스트를 종료하고 `LobbyScene`으로 돌아갑니다.

## 아이템 지급과 선택 표시

- 최초 인벤토리 표시와 전체 재지급 때는 내 아이템 전체를 등장시킬 수 있습니다. 이후 추가 지급은 새로 생긴 칸만 연출하고, 기존 아이템은 가능한 한 기존 표시를 유지합니다.
- 아이스박스 뚜껑을 열며 소리·입자를 재생하고 0.5초 기다립니다. 아이템은 0.08초 간격으로 출발하며, 각각 0.5초 동안 높이 1.5의 포물선을 따라 책상 위 자리로 이동합니다. 크기는 0에서 정상 크기로 커집니다. 마지막 출발 예약 후 이동용 0.5초와 추가 0.3초를 기다린 뒤 입자를 멈추고 뚜껑을 닫으며 지급 연출 상태를 해제합니다.
- 내 지급 연출 중에는 새 아이템 선택을 막습니다. 다만 서버의 준비 시간이 함께 멈추는 것은 아닙니다. 상대 인벤토리는 별도로 갱신하므로, 내 아이스박스 연출만 보고 모든 상대 아이템도 각자의 박스에서 출발한다고 판단하면 안 됩니다.
- 마우스를 올리면 공통 강조·외곽선 표시를 사용하며 기본 크기 배율은 1.15입니다. 서버가 선택을 확정하면 해당 아이템을 표시하고 충돌하는 다른 선택을 막습니다. 선택 표시와 3~4인전의 대상 조준 화살표는 별개입니다. 준비 완료 버튼은 눌린 이미지로 바뀌고 해당 준비 단계 동안 비활성화됩니다.
- 온도 구간 보상은 라운드마다 각 구간에서 한 번씩 지급합니다. 30°·20°·10°에서 1대1·봇전은 각각 랜덤 아이템 1개·2개·3개를 요청하고, 3~4인전은 각 1개씩 최대 보유 4개 제한 안에서 요청합니다. 준비 단계가 진행되는 도중 새 지급 연출이 시작될 수 있습니다.

## 아이템별 애니메이션

### 일반 아이템의 시작부터 종료까지

1. 서버가 확정한 행동의 연출 차례가 되면 1인칭 또는 상대 캐릭터용 동작을 선택하고, 아이템 스프라이트와 설정된 소리를 연결합니다.
2. 대부분의 현재 아이템 데이터는 `AnimDuration` 1.5초, `EffectDelay` 0.75초입니다. 효과 대기 시간이 지나면 해당 온도와 피해·방어·회복 반응을 표시합니다. 효과 지연을 따로 지정하지 않은 대체 경로는 애니메이션 중간을 사용합니다. 애니메이션 자체가 없으면 별도 대체 경로를 탈 수 있습니다.
3. 타격을 여러 번 표현하는 경우 `EffectInterval` 간격으로 반복합니다. 화면 반응만 반복하며 서버의 아이템 효과를 다시 실행하지는 않습니다.
4. 남은 애니메이션 시간을 기다린 뒤 행동자·1인칭·방어 대상을 기본 자세로 돌리고 1인칭에 들린 아이템을 지웁니다. 전용 후속 연출이 이어질 수도 있습니다. 이후 3~4인전은 아이템별 최소 시간을, 1대1은 사망 없는 전체 전투의 최소 시간을 채웁니다.

아래 동작 이름은 코드 확인을 위해 실제 애니메이터 식별자를 유지했습니다.

| 아이템 | 내 화면 / 상대 캐릭터 동작 | 주요 연출과 종료 |

### 먹이기·포옹·고양이의 연출

먹이기와 포옹은 2026-10-04 PLAN044부터 1대1·봇전·3~4인전에서 공통 경로를 사용합니다. 서버 판정은 기존 시점에 확정하며, 아래 시점은 화면에 결과를 보여주는 타이밍입니다.

**먹이기 — 아이스크림·아이스 아메리카노·삼계탕**

- 주는 사람: 기존 1인칭 양손 `feed` 또는 아이템에 지정된 상대 캐릭터 동작으로 시작합니다.
- 약 0.5초 후 손의 음식이 전달되는 시점에 결과 온도·타격 또는 방어를 표시합니다.
- 받는 사람: 1인칭은 손 없이 음식만 올라오는 기존 `use`, 다른 사람이 보는 캐릭터는 기존 `feed` 반응을 사용합니다. 주는 사람의 양손 동작을 받는 사람이 다시 재생하지 않습니다.
- 음식에 맞는 방어가 발동하면 받는 동작 대신 방어 모션 하나를 재생합니다. 현재 마스크는 음식 공격을 막고, 바람막이는 음식 필터에 반응하지 않습니다. 피해·소모 판정은 바뀌지 않습니다.
- 주는 클립과 받는 클립이 모두 끝날 때까지 기다립니다. 현재 클립 기준 약 1.85초이며, 더 긴 아이템 설정은 존중합니다. 임시 음식은 제거하고 기본 자세로 복귀합니다. 3~4인전은 기존 최소 행동 시간 3초를 채웁니다.

**포옹 티셔츠**

- 접근 1초 → 기존 포옹 약 1.017초 → 복귀 1초, 총 약 3.017초에 프레임 처리 시간이 더해집니다.
- 내가 행동할 때: 카메라가 대상까지 거리의 40%만큼 다가가며 대상 머리 쪽을 바라봅니다. 1인칭 손은 기존 1대1의 카메라 기준 배치를 빌려 함께 이동합니다. 4인 씬의 먼 손 앵커 때문에 팔끝이 공중에 뜨는 현상을 피하며, 끝나면 씬의 원래 위치로 복구합니다.
- 상대가 행동할 때: 기본 자세의 캐릭터 전체가 낮은 곡선을 그리며 1초 동안 대상 쪽으로 접근합니다. 준비 0.15초 후 남은 0.85초에 이동하며, 상체와 바지가 벌어지는 기존 점프 클립은 이 연출에서 사용하지 않습니다. 실제 네트워크 참가자 위치는 옮기지 않습니다.
- 내가 받을 때는 다가오는 캐릭터가 화면 중앙에 보이게 맞추고, 중앙 아이스박스보다 앞에 그립니다. 내 방어 모션은 그보다 앞에 표시합니다. 관전하는 사람에게는 두 캐릭터가 포개지지 않도록 받는 캐릭터 옆에서 멈춥니다. 선풍기는 원래 자리에 남습니다.
- 접근이 끝나면 포옹 동작을 시작하고, 동작 시작 약 0.5초 후 손이 닿을 때 결과 온도·타격·방어를 표시합니다. 1인칭 손이 내려가는 마지막 프레임까지 기다리고, 상대 캐릭터도 기본 자세로 돌아온 뒤 같은 낮은 곡선으로 원래 자리에 복귀합니다.
- 완전 방어는 접근 및 방어 반응을 유지하고 포옹 손동작을 생략합니다. 정상 종료·중단 모두 카메라·손·캐릭터 위치와 시선, 임시 표시 순서를 복구합니다. 일반 아이템 동작을 먼저 재생하지 않습니다.

**고양이**

- 내 아이템 표시를 빌릴 수 있으면 재사용하고, 상대 행동이면 임시 고양이 표시를 생성합니다. 빌려 쓰는 동안 이름표·마우스 강조·충돌 판정 등 충돌할 수 있는 표시를 숨깁니다.
- 잠자기·준비 0.3초 → 깨기 0.4초 → 포물선 점프 0.8초 → 뒤적이기 1.5초 → 퇴장·사라지기 0.5초입니다. 현재 데이터 기준 총 약 3.5초입니다.
- 빌린 오브젝트는 원래 상태로 복구하고, 임시 고양이는 제거하며, 행동자는 기본 자세로 돌립니다. 필요한 스프라이트가 없으면 시간을 맞춘 대체 경로를 사용합니다.
- 1대1은 고양이 순서 전에 온도를 표시하고 상대 아이템 기준점 중 목적지를 고릅니다. 3~4인전은 대상 위치를 사용하고 착지 시 효과 신호를 보냅니다. 인벤토리 변경 자체는 이미 서버 결과로 확정되어 있습니다.

## 미니게임의 시작·종료와 현재 제한

1. 서버가 현재 경기·라운드·턴·선택한 개별 아이템 정보를 포함한 시도 권한을 소유자에게만 전달합니다. 소유자 화면은 패널, 시작 안내, 타이머를 엽니다. 시작 안내 중에도 타이머가 흐르며 준비 단계를 멈추지 않습니다.
2. 제한 시간은 아이템에 설정된 시간과 남은 준비 시간 중 짧은 쪽을 사용합니다. 다른 참가자는 계속 준비합니다. 상대에게 별도의 '미니게임 진행 중' 표시는 보여주지 않습니다.
3. 목표를 달성하거나 시간이 끝나면 성공·실패를 즉시 전송합니다. 그 뒤 내 화면에 결과 등장 0.16초 → 유지 0.45초 → 사라지기 0.18초 → 패널 제거를 진행합니다. 합계 0.79초의 마무리는 서버가 성공 처리를 추가로 기다리는 시간이 아닙니다.
4. 서버가 경기 범위, 마감 시각, 개별 아이템, 행동자, 대상, 준비 완료 여부를 다시 검사합니다. 성공하면 행동을 예약하고 유효한 실패면 사용 횟수를 소모합니다. 준비 단계가 닫히면 화면을 취소하며 오래된 제출로 새 공격을 예약할 수 없습니다.

## 사망과 결과 화면의 시작·종료

### 얼어붙기

- 사망 이벤트를 재생하거나 1대1 라운드 종료 경로가 사망을 요청하면 시작합니다. 충돌하는 피해·애니메이션 처리를 정리하고 얼어붙는 상태로 전환합니다.
- 얼음 이미지 1을 표시하고 0.167초 후 이미지 2, 다시 0.167초 후 이미지 3을 표시한 뒤 1.5초 유지합니다.
- 깨지는 소리·입자를 재생하고 강도 0.3으로 0.5초 카메라 흔들림을 요청합니다. 일반적인 3~4인전 사망은 약 1.83초와 프레임 처리 시간 후 임시 유령을 보여줍니다.
- 종료용 표시 플래그가 켜져 있으면 최종 외형을 정리하기 전 1.5초 더 유지합니다. 일부 라운드 종료 전용 사망 경로도 이 플래그를 사용하므로, 추가 대기가 있다고 반드시 경기 전체가 끝난 것은 아닙니다.
- 부활 시 얼음·유령·임시 사망 외형을 해제하고 생존 상태 표시로 복구합니다. 다음 라운드 게이지 회복은 별도 화면 보간이며 매 프레임 실제 회복을 추가하는 기능이 아닙니다.

### 결과 화면

- 현재 상태와 맞춰진 결과 알림에서 시작합니다. 뒤쪽 클릭을 막고 1초 동안 검은 화면으로 전환합니다.
- 결과 글자는 20픽셀 아래에서 0.8초 동안 올라오며 나타납니다.
- **라운드만 끝났을 때:** 글자를 1.5초 유지하고 화면·글자를 1초 동안 사라지게 한 뒤 결과 화면을 숨깁니다. 합계 약 4.3초입니다. 서버의 라운드 진행 대기는 별도 6초입니다.
- **경기가 끝났을 때:** 글자가 올라온 후 결과를 유지하고 모드에 맞는 버튼을 표시합니다. 온라인 1대1은 재대결 투표 상태를 따르고, 봇전은 직접 선택할 때까지 기다리며, 3~4인전은 로비 버튼과 최종 결과 표시 후 3초 자동 퇴장을 사용합니다.
- 새 준비 단계, 씬 해제, 화면 오브젝트 제거 시 이전 결과 처리와 버튼·타이머 상태를 정리합니다.

### 그 밖의 화면 반응과 완료 판정

- 일반 피해 반짝임은 약 0.15초에 걸쳐 사라집니다. 방어 중이라면 방어 애니메이션을 유지하며 다른 공격 동작으로 덮어쓰지 않습니다.
- 내 화면의 서리·온기 효과는 0.2초 나타나기 → 0.16초 유지 → 0.7초 사라지기입니다. 새 효과가 기존 효과를 교체할 수 있습니다. 3~4인전의 공통 타격 경로와 1대1의 서리 호출 경로가 완전히 같지는 않습니다.
- 일반 타격 카메라 흔들림은 해당 분기에서 요청할 때 강도 0.1로 0.15초 적용합니다. 사용자 설정으로 줄이거나 끌 수 있습니다. 모든 행동마다 화면 전환을 하는 방식은 아닙니다.
- 전투 완료 시 임시 위치, 빌린 아이템, 인벤토리 잠금을 정리하고 관련 표시를 기본 자세로 복귀시킵니다. 임시 온도·행동자 표시를 지우고 완료 응답을 보냅니다. 장식용 반짝임·재사용 입자에는 잔여 시간이 있을 수 있습니다. **완료 응답이 모든 입자 소멸이나 게이지 이동 종료까지 의미하지는 않습니다.**
- 연결 해제, 오래된 세션, 씬 이동은 이전 연출의 유효성을 해제합니다. 완료 대기는 실제 사람 화면만 추적합니다. 응답 제한 시간이 지나면 경고를 기록하고 무한 대기 대신 정해진 경로로 계속 진행합니다. 이 대체 처리가 모든 클라이언트에서 모든 프레임을 표시했다는 증거는 아닙니다.

## 이후 수정할 때 유지해야 할 차이

1. 실제 게임 결과 확정, 화면의 타격 시점, 전체 연출 완료를 구분해야 합니다.
2. 1대1·봇전의 전체 전투 시간과 3~4인전의 행동별 시간을 구분해야 합니다.
3. 방어는 공격에 맞춘 동시 반응을 유지해야 합니다. 별도 방어 차례를 추가하거나 선풍기 반복 타격마다 방어 동작을 재시작하면 안 됩니다.
4. 3~4인전 특수 아이템의 접촉 시점 효과를 유지하되, 1대1도 이미 같은 방식이라고 판단하면 안 됩니다.
5. 5킬을 만든 행동의 연출은 끝낼 수 있지만 그 뒤의 행동은 실행하면 안 됩니다.
6. 일반 아이템의 마우스 조준과 현재 별도로 구현된 유령의 대상 클릭을 구분해야 합니다.
7. 아이템 선택만으로 선풍기가 멈춘다고 판단하거나, 현재 봇 기본값을 완성된 난이도 밸런스로 판단하면 안 됩니다.

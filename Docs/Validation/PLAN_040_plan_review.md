# PLAN 040 — 후속 기능 계획 검증

> 날짜: 2026-09-30  
> 대상: [후속 기능 통합 상세 계획](../Plans/PLAN_040_followup_features.md)과 PLAN 037 연결부  
> 유형: **현재 소스·기존 계약과 대조한 자체 계획 검토**. 독립 에이전트 교차 검증 또는 Unity 실행 검증이 아니다.  
> 결론: **계획 준비도 95/100. R10부터 기존 순서로 진행 가능.** 미확정 데이터 활성화와 전체 출시 승인은 별도다.

## 1. 판단 범위

- 최신 사용자 결정: 핫팩 유지, 상대 미니게임 표시 없음, Codex가 옷장 UI·UX 설계, 그림 교체만 지원, 타로 제외, 기존 Solo/멀티 규칙 보존.
- 기준 계획: PLAN 037의 상위 계획·실행 상세·파일별 작업 패키지, PLAN 036 솔로·BT 문서, PLAN 039 맵 및 기존 검증 원장.
- 소스 경계: LobbySettingsView/GameAudioManager/CameraShake/MatchHudPresenter, Cosmetic 관련 소유권, Lobby/Session 전송 경계, Solo 설정 SO·resolver·bootstrap·coordinator, 아이템 추첨 호출.
- R00~R09는 기존 실행 원장에 통과 기록이 있다. 이번에는 그 검사를 다시 실행하지 않았으며 후속 기능의 통과 증거로 사용하지 않았다.

자체 검토 범위에서 **즉시 R10 착수를 막는 미해결 계획 모순은 발견하지 않았다.** 실제 결함의 유무와 실행 안정성은 각 작업의 필수 검사로 판단해야 한다.

## 4. 문서 정적 검사

- 선행 관계 **24개 작업, 37개 연결**을 검사했다. 순환 의존 0, 정의되지 않은 선행 작업 0, 필수 작업 ID 누락 0. R09는 이미 완료된 외부 시작점이다.
- 본문의 명시적인 `Assets/...` 경로 **7개**의 존재를 확인했다. 나머지 클래스·후보 책임은 해당 소유 디렉터리와 현재 코드에서 확인하거나 계획 후보로 구분했다.
- 두 새 문서의 로컬 Markdown 링크, 코드 블록 짝, 필수 작업 목록과 모드별 검사·승인 대기 표시를 확인했다. 구체적인 최종 검사 결과는 아래 완료 기록에 남긴다.
- 링크 추가: PLAN 037 상위/실행 상세/작업 패키지, ACTIVE_CONTEXT. 구현 진도는 **다음 R10** 그대로 유지한다.
- 소스 보존 확인 범위: `Assets/Scripts`, `Assets/Editor`, `Assets/Scenes`, `Assets/Prefabs`, `Assets/Resources`, `Assets/Data`, `Packages`, `ProjectSettings` 중 존재하는 경로. 확인 대상 **1,359개 파일**의 상대 경로와 SHA-256을 합쳐 작업 전후 동일함을 확인했다. 전체 저장소의 모든 외부 산출물을 검사했다는 의미는 아니다.
- 기준 합산 SHA-256: `A3DDFA6D3DF511592397A8DBFB6C56041FF0433C64732D9EC1D0A2F9C9FAEBB4`.

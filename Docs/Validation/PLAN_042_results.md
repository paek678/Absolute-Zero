## 발견 후 수정한 핵심 문제

1. Multi 특정 자리만 로봇으로 고정되어 있던 씬 참조 → 사람 원본 통일, 로봇은 Solo 봇 프로필로 선택.
2. 장착 갱신/해제 때 기본 로봇 외형까지 지워질 수 있음 → 기본 프로필과 장착을 원본 포즈 기준으로 합성.
3. 일부 경로/그림 실패와 빈 필수 아틀라스가 성공처럼 보임 → 후보 전체 사전 검사, 적용 결과 전달, 이전 정상 구성 복원과 재시도.
4. 같은 표시 객체 재사용 시 이전 소유자의 정리, 비활성화 후 복구 누락 → 소유권 검사와 중지/재개/종료 분리.
5. 장식의 생명 상태·정렬·좌우 반전 → 표시 캐시/정책을 커밋에 포함, 몸과 함께 숨김/복구, 꼬리 부착 위치도 반전.

## 검사 범위와 잔여 수동 검수

- 이번 통과는 동일 PC의 독립 프로세스 및 실제 Relay, 실제 UI/캐릭터와 Editor 회귀에 대한 판정입니다. 모든 네트워크 환경에서 무결함이라는 보장은 아닙니다.
- 다른 PC/다른 GPU/실제 지연·패킷 손실 환경, 장시간 반복 플레이, 데스크톱 최종 합성 화면의 육안 확인은 별도 잔여 검수입니다. 숨긴 창의 검정 캡처는 증거에서 제외했고 카메라 직접 렌더와 네이티브 스크린샷을 혼용하지 않았습니다.
- 악성 원시 RPC 패킷 주입 검사는 미실행. 기존 권한 경계는 변경하지 않았으며 관련 코드, DTO/설정/요청 상태 검사와 정상 실제 승인 경로를 확인했습니다.
- 게임 규칙·BT 판단·아이템/온도·맵 배치·기존 모자 맞춤값은 이번 구현 범위에서 변경하지 않았습니다.
